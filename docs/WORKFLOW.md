# 独立后台文献翻译工作流

DSH提供工具入口；固定本机服务负责后台作业，独立DeepSeek API负责翻译、有限返修和独立复核。日常批处理不要求聊天窗口持续在线，不自动调用GPT修复。Dot接口保留，当前部署使用Codex角色客户端。

## 一批论文如何处理

1. 从Zotero选中条目或分类读取原始PDF，核对父子关系、SHA256与物理页数。冻结来源和批次清单，去重并列出缺全文及已有译本。
2. 在断网、只读根、无特权容器中提取原生段落。版本化缓存保留旧证据；双栏按文字块排序。缺失负号、数学字体误编码和扫描页必须明确标记，不能把提取文字当作原图的等价替代。
3. 建立本篇背景包，从已索引资料检索最多10个本地、5个已验证公开来源。使用FTS；候选术语和翻译记忆只有独立验收后才能晋升。当前没有自动新增公开网页的通用网络执行器。
4. 通过独立DeepSeek API进行初译，保留公式占位符、引用和原始数据，翻译表格文字。密钥由主机提供商代理持有，容器不联网、看不到真实密钥。
5. 生成中文阅读PDF与原文左、中文右的双语PDF。允许重排与续页，每页标明原文物理页码。原图及数据保留，提供中文标签说明；可识别的独立公式从原文恢复，并核对图像证据。
6. 程序检查字号、裁切、边界和页码映射。独立API复核逐一覆盖全部原文页、中文页和双语页；部分负面初检只能用于返修，不能授予验收。
7. 最多两轮语义返修。只修改冻结、可编辑文字块；有证据的空白位置可容纳正常字号译文，空间不足才续页。数值及源文引用校验继续执行。图像转写候选绑定原图SHA，需独立逐条核验。
8. 新候选重新验收。通过后发布两份PDF，再回挂Zotero；未通过的保留译稿和问题包，继续其他论文，不将其计作合格交付。

## 预算、权限与恢复

- 默认单篇5元提醒、10元硬上限；试点累计15元。相同原文与页码范围跨修订共用累计额度，不清零旧费用或未知请求。批次摘要显示具体预算，维护入口不能擅自提高。
- 服务API只接受固定动作、已登记来源与批次ID；DSH不获维护凭据、任意路径、命令或网络权限。安装与外部连接在可信维护步骤完成。
- 正常生产就绪与精确清单放行分开。某篇在有限修复后失败时，维护工具可根据既有用户指令、完整原清单及问题包放行剩余的同一批；它不授予其他批次权限，也不绕过逐篇验收。
- 已保存翻译和付费响应可按私有收据恢复。超时不等于进程已停止；恢复先核查同一容器和请求状态，未知费用保留，不盲目重发。
- 每次候选变化使旧验收失效。预算不足、连接失败或不能可靠修复时生成问题包；不自动调用GPT或增加返修轮次。
- Zotero只回挂当前已验收、哈希相符的两份PDF。官方本机写入桥需要一次明确授权；未接通时保留本地译本和待归档状态，不能伪报回挂成功。

## 入口与当前限制

安装、角色文件与恢复见[安装恢复](INSTALLATION_RECOVERY.md)，API见[后台服务接入](BACKGROUND_SERVICE.md)。精确批次放行收据有有效期，到期自动暂停新请求；它不是无限期、无限范围授权。Qwen-MT仅保留关闭的接口。

当前仍为测试版。真实原文旧字体、复杂表格和排版残留可能导致某些论文未通过；完整新电脑冷安装、DSH新插件实机安装和真实Zotero写回尚未完成端到端验收。详见[测试记录](VALIDATION.md)。
