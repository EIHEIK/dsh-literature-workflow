# 固定安装、登录启动与回滚

**当前部署暂缓Dot，由GPT-6.1 Sol做必要监督。** 收据核查实际Codex宿主；下文旧Dot前提保留供以后接入。本机已安装修正版并运行精确清单的受控批处理；通用验证边界见[测试记录](VALIDATION.md)，实际作业状态以私有运行指针及后台查询为准。

维护入口为 `scripts/install_service.py`，不暴露给 Dot 或 DSH 模型工具。首次配置使用 `runtime/service_main.py provision`；已有服务配置不会被覆盖初始化。维护前先用受信任的停止入口结束后台，不能依据旧 PID 文件直接杀进程。

## 安装机制

`install --config <私有 service.json> --releases <版本目录>` 将白名单源码复制到按完整清单哈希命名的版本目录。检查所有内容和额外文件，生成安装收据。当前复用已存在的 Python 环境，冻结 Python 核心可执行文件、版本及 PyMuPDF 文件指纹；没有声称对整个 Windows/Python 标准库进行了位级封装，也没有完成无依赖新电脑的一键安装。

激活前取得后台和索引管理器的独占锁，运行中拒绝升级。备份私有配置和 SQLite 的一致性副本，原数据目录保持。安装后付费开关重置为关闭，既有就绪结论不能自动覆盖新运行代码。

`verify --config ...` 检查安装内容和运行依赖。`start --config ...` 以隐藏 pythonw 进程启动固定 launcher；返回进程号只表示已创建启动进程，必须再用状态接口确认服务响应。直接运行已安装 `service_main.py` 同样检查安装收据。

## 登录入口

`enable-login --config ...` 只登记当前用户的 `FlyLiteratureWorkflowV2` 登录项，不需要管理员权限、不保存 Windows 密码。固定入口调用私有目录内的 `login_bootstrap.pyw`，再读取当前安装收据并启动已验证版本。升级后同步该入口；遇到不属于本安装的同名项或手改 bootstrap，拒绝覆盖。

短入口用于处理 Windows 应用路径重定向后的长目录。[Microsoft 文档](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)将 Run 项命令长度限制为260字符；安装器检查 UTF-16 长度，超出即报告，不登记一个无法启动的命令。

`disable-login --config ...` 仅移除已核对归属的登录项；保留代码、配置、数据库和所有论文。它不等于停止当前正在运行的后台。

实际执行登记命令能验证入口、依赖、后台重开和端口；不能替代真实注销/重新登录或 Windows 重启验收。当前已经执行同一登录命令成功，尚未为测试而注销用户或重启电脑。

## 升级与恢复

每个版本均保留，升级不删除上一版。`rollback --config ... --installation <历史安装ID>` 只切换到记录在案且完整性通过、数据库兼容版本相同的代码；**不还原旧数据库，不回退累计费用或新归档收据**。回滚同样关闭付费，暂停和重新验收按当前运行版本处理。旧版本若不兼容数据库则拒绝，不能强行恢复旧备份冒充升级前状态。

后台与作业各有自己的恢复机制：安装回滚不授权清除工作容器、未知费用或验收失败。工作容器状态未知时先检查原身份；不能因为启动响应超时就创建第二个 worker。后台退出不代表 DSH 或 Dot 可以直接启动旧 RC 的独立 worker。

## 试点与正式生产

正式生产要求完整真实验收；试点使用单独的、最长七天有效的维护就绪记录，绑定当前代码、镜像及精确批次摘要。当前要求离线链路、实际Sol宿主和既有真实用户指令绑定确认已验证；Dot暂缓，不再作为前提。试点不要求“试点已通过”才能开始。没有维护签发记录时`pilotReady=false`。

每次派发前重查记录。过期、代码/镜像变化或摘要不在许可中时暂停对应批次；已发出的请求仍正常计量，不能抹去费用。用户批次确认、15元累计试点预算、10元单篇硬上限及全部质量要求继续有效。模型接口没有签发就绪记录或提高预算的能力。

## 当前本机证据

- 本机已安装不可变修正版，用户登录项已登记；实际执行同一命令可恢复后台并保持端口，尚未验证真实Windows注销/重启触发。实际安装与运行指针只保存在私有配置中，不通过手改安装目录更新。
- 原首篇有限失败后，`continue_original_batch.py`维护入口已核对原授权范围、无在途/未知费用和问题包，真实启动原其余14篇；一般`productionReady=false`，精确批次`scopedBatchReady=true`。这不是声称首篇已通过，也不开放其他论文或批次。
- 精确清单收据24小时有效；到期暂停新请求，历史费用保留。已有批次通过`get_status`和既有批次ID恢复观察，不能因维护响应丢失再运行一遍创建流程。Zotero新通道仍需明确的一次授权。
- DSH 安装副本尚未替换。已核对其实际 CLI 为桌面安装附带的 `runtime/cli/bin/dsh.cmd`，`plugin --profile desktop` 将插件管理参数转交当前 profile 的 pnpm；后续安装前须再次备份 profile 和旧插件。
